# EMC 建模：小分子体系

* **EMC 版本：** 9.4.4
* **EMC Setup 版本：** 5.3
* **翻译状态：** 完整教程

---

## 1. 概述

EMC 支持从 SMILES 字符串或预定义库构建小分子体系。这是 EMC 最基本的功能，也是理解 EMC 建模逻辑的最佳入口。

---

## 2. 从空文件到小分子体系

### 2.1 使用 EMC Setup（推荐）

最简单的方式是通过 EMC Setup 的命令行：

```bash
perl /opt/emc-9.4.4/scripts/emc.pl \
  -field=opls-aa \
  -density=0.997 \
  pure_water 1 1000 water
```

**逐行解释：**

| 参数 | 含义 |
|------|------|
| `-field=opls-aa` | 使用 OPLS-AA 力场。EMC 会查找 `./field/opls/` 中的拓扑和参数文件 |
| `-density=0.997` | 目标密度 0.997 g/cm³（水在 298K 的密度） |
| `pure_water` | 项目名称（任意字符串，用作目录名） |
| `1` | 1 个相（单相体系） |
| `1000 water` | 1000 个水分子。`water` 是 EMC 内建分子名 |

### 2.2 EMC Setup 做了什么

EMC Setup 在这个命令中执行了以下步骤：

1. **查找 water 的化学定义：** 在力场文件中查找 `water` 的 SMILES、原子类型、键、角等
2. **计算体系大小：** 根据 1000 个水分子和目标密度 0.997 g/cm³ 计算盒子尺寸
3. **生成构建脚本 (build.emc)：** EMC 主程序输入，包含分子构建和 MC 采样指令
4. **生成 LAMMPS 输入 (system.in)：** 完整的 LAMMPS 输入脚本

### 2.3 执行构建

```bash
cd pure_water/build
emc -nthreads=4 build.emc
```

### 2.4 运行 LAMMPS

```bash
lmp -in system.in -log run.log
```

## 3. EMC 内建分子名称

EMC 内建了许多常见分子的化学定义。以下是通过 Setup 可以直接使用的分子名：

| 分子名 | 化学式 | 力场 |
|--------|--------|------|
| `water` | H₂O | OPLS, CHARMM, PCFF |
| `ethanol` | C₂H₅OH | OPLS, CHARMM, TraPPE |
| `methanol` | CH₃OH | OPLS, TraPPE |
| `benzene` | C₆H₆ | OPLS, CHARMM, TraPPE |
| `cyclohexane` | C₆H₁₂ | OPLS |
| `n-hexane` | C₆H₁₄ | OPLS, TraPPE |
| `n-octane` | C₈H₁₈ | OPLS, TraPPE |
| `acetone` | (CH₃)₂CO | OPLS |
| `dmso` | (CH₃)₂SO | OPLS |
| `toluene` | C₇H₈ | OPLS |
| `glycerol` | C₃H₈O₃ | OPLS |
| `urea` | (NH₂)₂CO | OPLS |

**编者注：** 完整的内建分子列表取决于力场。可以通过查看 `/opt/emc-9.4.4/field/opls/` 等目录中的 `.top` 文件来了解完整列表。

## 4. 混合物体系

### 4.1 水 + 乙醇混合物

```bash
perl /opt/emc-9.4.4/scripts/emc.pl \
  -field=opls-aa \
  -density=0.9 \
  water_ethanol 1 500 water + 200 ethanol
```

关键语法：`+` 分隔不同组分。

### 4.2 多组分溶液

```bash
perl /opt/emc-9.4.4/scripts/emc.pl \
  -field=opls-aa \
  -density=1.0 \
  urea_solution 1 1000 water + 50 urea
```

### 4.3 使用质量分数

```bash
perl /opt/emc-9.4.4/scripts/emc.pl \
  -field=opls-aa \
  -density=0.85 \
  -fraction=mass \
  mix 1 80 water + 20 ethanol
```

EMC 会根据质量分数自动转换分子数。

## 5. 使用 SMILES 自定义分子

对于不在 EMC 内建库中的分子，可以使用 SMILES 字符串：

```bash
perl /opt/emc-9.4.4/scripts/emc.pl \
  -field=opls-aa \
  -density=0.8 \
  custom_molecule 1 200 'CCOC'   # 乙醚 (diethyl ether) 的 SMILES
```

> **编者注：** EMC 会自动解析 SMILES、生成 3D 构型并进行力场 typing。但并非所有 SMILES 字符串都能被所有力场识别。如果力场文件中缺少对应的原子类型参数，EMC 将报错。
